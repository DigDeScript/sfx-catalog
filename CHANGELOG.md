# Release notes

## 1.1.1 — prepared for publication

- Embeds the DigDeScript logo in the Windows executable at seven icon sizes.
- Sets the Windows taskbar application identity and bundles the application icon.
- Adds automatic discovery and indexing of an installed Fairlight Sound Library without replacing the selected library.
- Includes the unified Free/Pro application and the matched Resolve panel.

The build passed 211 automated tests, packaged binary checks and a packaged smoke test. This is not a guarantee of compatibility with every computer.

The current package still includes a development-build notice and does not include a finalized application EULA. It is retained as a draft release pending publication review.
