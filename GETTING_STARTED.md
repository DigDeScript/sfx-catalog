# Getting started on Windows

1. Download the application ZIP from the official website or a published GitHub release.
2. Extract the entire archive to a folder you can write to.
3. Open `SFXCatalog.exe`. Do not move the executable away from its accompanying files.
4. Select a local sound folder and let the application scan it.
5. Search, filter and preview sounds using the waveform player.

Python does not need to be installed separately. Catalog data is stored under `%LOCALAPPDATA%\SoundEffectsCatalog`, not only beside the executable. Copying the application folder is not a backup of your catalog or a transfer of a Pro activation.

To use downloaded online sounds offline, extract the sound-library ZIP and select that sound folder for scanning.

To activate Pro, use **Help → Activate SFX Catalog Pro**. Keep your license key private. Contact support@digdescript.com if you need help.

If Windows displays a security warning, verify the download source and package hash before deciding whether to run it. Do not disable antivirus protection.
