# SFX Catalog

Sound-effects library software by DigDeScript. See the [product page](https://digdescript.com/software?product=sfx-catalog) for available platforms, downloads, current pricing and purchase options. See [macOS support](https://digdescript.com/support/sfx-catalog/resolve-panel#macos) for its status.

This repository contains product information, screenshots and packaged releases. It does not contain the proprietary SFX Catalog application source code.

One application runs in Free mode and unlocks Pro features with an activated license. Download the Windows ZIP or Linux tar.gz attached to a published release, not GitHub's automatically generated **Source code** archives.

Windows and Linux packages are available from the latest published release. The official website uses those same GitHub release assets for its download links.

## Buy a Pro activation key

Purchase SFX Catalog Pro on the [official DigDeScript product page](https://digdescript.com/software?product=sfx-catalog) using **Buy Pro**. Current pricing and purchase terms are shown on the website and at checkout; GitHub hosts downloads, not sales.

After a successful purchase, the activation key is sent to the email address used at checkout. In SFX Catalog, select **Help → Activate SFX Catalog Pro** and enter the key. There is no separate Pro installer: the same application switches from Free to Pro.

The one-time license supports up to three active computers and includes SFX Catalog 1.x updates. Version 2.0 is not included. Use [license self-service](https://digdescript.com/license-recovery) to manage devices or recover access to an existing license.

## Support

Contact [support@digdescript.com](mailto:support@digdescript.com). Do not post license keys or personal information in public issues.

Linux requires FFmpeg and ffprobe on the user's computer. Read the included `README-Linux.txt` before installation. The optional SFX Catalog panel requires **DaVinci Resolve Studio**; DaVinci Resolve Free is not supported for the panel.
