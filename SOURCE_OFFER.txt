SOURCE CODE OFFER FOR LGPL COMPONENTS

Sound Effects Catalog is distributed with unmodified LGPL components, including
Qt for Python / Qt and a dedicated FFmpeg build.

For at least three years after receiving this program, a recipient may request
the complete corresponding source code and build information for the LGPL
components distributed with the program, at no more than the reasonable cost of
providing the copy.

Distributor contact:

    https://digdescript.com

The build records and corresponding-source preparation tools identify and verify
the source archives for the distributed components. The Windows package uses Qt
6.11.1 and the dedicated FFmpeg 7.1.1 build. The Linux package uses Qt 6.9.3 for
glibc 2.28 compatibility and includes the runtime components selected by the Linux
packaging process.

The FFmpeg build scripts and exact configuration are included with the source
project. The source archive manifest records download locations and SHA-256
hashes.

This offer applies only to the LGPL components and does not grant rights to the
proprietary Sound Effects Catalog application source code.
